# SQL Data Analytics – Pagila

A practical SQL data analytics project using PostgreSQL and the Pagila database.

## Project Structure

```text
sql-data-analytics-pagila/
├── README.md
├── SQL_Data_Analytics_75_Questions_ONLY.sql
└── SQL_Data_Analytics_75_Answers.sql
```

## About This Project

This project contains 75 SQL questions designed to practise practical data analytics skills using PostgreSQL and the Pagila database.

The questions cover:

- Basic SQL
- Aggregations and `HAVING`
- `JOIN`s
- `CASE` statements
- Date functions
- Subqueries
- Correlated subqueries
- CTEs
- Business-style SQL problems
- Mixed SQL analytics problems

## Files

**SQL_Data_Analytics_75_Questions_ONLY.sql**  
Contains all 75 practice questions without solutions.

**SQL_Data_Analytics_75_Answers.sql**  
Contains the SQL solutions for the 75 questions.

## Tools Used

- PostgreSQL
- pgAdmin 4
- SQL
- Pagila sample database

## Purpose

The purpose of this project is to demonstrate practical SQL skills relevant to Junior Data Analyst and Graduate Data Analyst roles.

## Database

The project uses the Pagila PostgreSQL sample database, which contains data related to films, customers, rentals, payments, staff, stores and categories.
